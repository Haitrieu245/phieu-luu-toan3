# Phiêu Lưu Toán 3

Game học Toán lớp 3 (sách *Kết nối tri thức với cuộc sống*, tập một) — Bài 5 đến Bài 12.
Chạy trên trình duyệt, cài được lên iPhone/Android như một app và chơi được khi không có mạng.

- Mã nguồn: `src/` (khung HTML, CSS, logic game, file PWA)
- Build: `./build.sh` → sinh `dist/` (bản web app), `index.html` (bản mở trực tiếp)
- Mỗi lần đẩy lên nhánh `main`, GitHub Actions tự build và đăng lên GitHub Pages.
